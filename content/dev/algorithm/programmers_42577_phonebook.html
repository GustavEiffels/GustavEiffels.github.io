1

문제 개요

오랜만의 코딩 테스트 문제였다.
프로그래머스 42577번 문제이고 접두어를 찾는 문제였다.
코딩 테스트 문제에 사용한 언어는 Java 이다.

2

첫 접근 - 정렬이 필요하다

문제를 본 순간 든 생각은
일단 정렬이 필요하다고 생각이 들었다.

N개의 숫자 중 하나만 접두어로 선정하여 비교해야 하며,
일치하는 숫자가 없다고 하였으니, 글자 길이로 오름차순 정렬을 하여
최대한 비교 대상을 점진적으로 줄여 나가는 것이 좋다고 생각했다.

3

시행착오 - 숫자로 변환했더니 0이 사라진다

그래서 무지성으로 숫자 문자열을 숫자로 변경하여 오름차순 정렬 후
다시 문자열 배열로 만들려고 했는데, 이럴 경우 숫자 문자열의 숫자가 수정되는
경우가 발생한다. 

ex ) 010 -> 10
4

해결 - 문자열 그대로, 사전순 정렬

그래서 문자열 배열을 그대로 사용했고 문제를 더 쉽게 풀 수 있었다.

숫자도 문자로 보기 때문에 이런 3가지 숫자가 존재할 때
문자열 배열로 정렬한다면 이렇게 나열이 된다. 

ex ) "802", "91", "2400" -> "2400", "802", "91"

여기서 제공된 배열을 예로 들자면 이렇게 나열이 된다. 

ex ) "119", "97674223", "1195524421" -> "119", "1195524421", "97674223"

여기서 Java String의 method startWith를 함께 써주어
문제를 보다 빠르게 풀 수 있었다.

5

최종 코드

N42577.java 
package com.test.programmers.hash;

import java.util.Arrays;

public class N42577 {

    public static void main(String[] args) {
        String[] phone_book = {"119", "97674223", "1195524421"};
        System.out.println(solution(phone_book));
    }

    public static boolean solution(String[] phone_book) {
        Arrays.sort(phone_book);
        for (int i = 0; i < phone_book.length - 1; i++) {
            if (phone_book[i + 1].startsWith(phone_book[i])) {
                return false;
            }
        }
        return true;
    }
}
