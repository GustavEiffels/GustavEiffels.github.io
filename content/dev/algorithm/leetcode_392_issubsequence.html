Is Subsequence

되감기 없는 투 포인터로 O(t.length) 한 번에 부분수열 여부를 판별한 과정

언어: Java 분류: 투 포인터 핵심 기법: t는 앞으로만, s쪽 포인터도 앞으로만 이동

leetcode.com/problems/is-subsequence

CH 1

풀이 회고

1

문제 개요

문자열 s가 문자열 t의 부분수열(subsequence)인지 판별하는 문제다.
부분수열은 순서를 유지한 채 일부 문자를 건너뛰며 뽑아낸 문자열이라, s의 문자를 등장 순서대로 t 안에서 순서를 지키며 다 찾을 수 있는지가 핵심이다.

2

손으로 구조부터 정리

노트에 먼저 적은 구조는 s를 문자 배열(sequence)로 옮겨두고, 지금 맞춰야 할 목표 문자를
가리키는 포인터(sequenceIndex)를 하나 두는 방식이었다.

손 풀이 - 구조 스케치 
char[] sequence = s.toCharArray 대상
int sequenceIndex = 0
char currentChar = sequence[sequenceIndex]

for (ch : t의 각 문자) {
    if (ch == currentChar) {
        sequenceIndex++
        currentChar = sequence[sequenceIndex]   // 다음 목표로 이동
    }
}

t를 한 글자씩 훑으면서, "지금 찾아야 할 s의 글자"와 같을 때만 포인터를 한 칸 옮긴다는 아이디어다.
t는 절대 되감지 않고 앞으로만 가고, s쪽 포인터도 절대 되감지 않고 앞으로만 간다 - 그래서 O(t.length) 한 번 순회로 끝난다.

3

경계 조건 추가

손 풀이 구조를 코드로 옮기면서 아래 두 가지를 먼저 처리해야 한다는 걸 넣었다.

sequenceIndex가 sequence.length를 넘는 순간 바로 리턴 s의 모든 문자를 다 찾았으면 그 즉시 true를 반환해야 한다. 아니면 currentChar = sequence[sequenceIndex]에서 ArrayIndexOutOfBoundsException이 난다 - s를 다 찾고 나서도 배열 다음 칸을 또 읽으려 하기 때문이다.
s가 빈 문자열이면 무조건 true, t가 빈 문자열이면 무조건 false 빈 부분수열은 어떤 문자열에도 포함되고, s가 비어있지 않은데 t가 비어있으면 애초에 찾을 문자가 없으므로 바로 false로 처리해서 루프 진입 전에 걸러냈다.
4

최종 코드

IsSubsequence.java 
public boolean isSubsequence(String s, String t) {
    if(s.length() == 0) return true;
    if(t.length() == 0) return false;
    if(s.length() > t.length()) return false;

    char[] sequence = new char[s.length()];
    for(int i = 0; i<s.length(); i++){
        sequence[i] = s.charAt(i);
    }
    int sequenceIndex = 0;
    char currentChar = sequence[sequenceIndex];
    for(char ch : t.toCharArray()){
        if(ch == currentChar){
            sequenceIndex++;
            if(sequenceIndex == sequence.length) return true;
            currentChar = sequence[sequenceIndex];
        }
    }
    return false;
}

s.length() > t.length()는 사실 없어도 로직상 정답은 나오지만, t를 끝까지 순회하지 않고
즉시 false로 끝낼 수 있는 조기 종료(early exit)라 넣어뒀다.

5

Takeaway

  • t는 앞으로만, s쪽 포인터도 앞으로만 - 되감기가 없어서 O(t.length) 한 번 순회로 충분하다.
  • 포인터가 s.length에 도달하는 즉시 true로 끝내지 않으면 다음 배열 접근에서 인덱스 초과가 난다.
  • s/t 둘 다 빈 문자열인 경우를 루프 진입 전에 먼저 걸러두면 본 로직이 단순해진다.
