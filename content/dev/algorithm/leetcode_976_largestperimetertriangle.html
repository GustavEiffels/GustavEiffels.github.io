Largest Perimeter Triangle

정렬 후 뒤에서부터 탐색하는 그리디로 삼각형이 성립하는 최대 둘레를 구하는 문제 풀이 과정

언어: Java 분류: 그리디 핵심 기법: 정렬 + 뒤에서부터 탐색

leetcode.com/problems/largest-perimeter-triangle

1

문제 개요

배열에서 세 값을 골라 삼각형을 만들 수 있는 조합 중 둘레가 가장 큰 값을 구하는 문제다. 세 변 a <= b <= c가 삼각형을 이루려면 a + b > c 조건만 확인하면 된다 - 가장 긴 변보다 나머지 두 변의 합이 커야 한다는 삼각부등식이다.

둘레를 최대화하려면 가능한 한 큰 값들로 조합을 만드는 게 유리하므로,
정렬 후 가장 큰 값들부터 순서대로 조건을 검사하는 그리디 접근이 자연스럽다.

2

풀이 - 정렬 + 뒤에서부터 탐색

오름차순 정렬 후 배열 끝에서부터 연속한 세 값 nums[i-2], nums[i-1], nums[i]를 삼각부등식으로 검사한다. 가장 긴 변이 nums[i]이므로 nums[i] < nums[i-1] + nums[i-2]만 확인하면 되고, 조건을 만족하는 첫 조합이 곧 그 시점에서 만들 수 있는 최대 둘레다.

조건을 만족하지 않으면 nums[i]를 통째로 버려도 안전한 이유 정렬된 배열에서 nums[i]가 nums[i-1], nums[i-2]와 삼각형을 이루지 못하면, nums[i]는 nums[i-1] + nums[i-2]보다 크거나 같다. 이때 nums[i-2] 자리에 더 작은 값을 넣으면 우변(합)은 더 작아지므로 조건은 오히려 더 나빠진다. 즉 nums[i]는 어떤 두 값과 묶여도 가장 긴 변으로 삼각형을 만들 수 없으므로 완전히 배제해도 된다.
LargestPerimeterTriangle.java 
public int largestPerimeter(int[] nums) {
    Arrays.sort(nums);
    int result = 0;
    for (int i = nums.length - 1; i >= 2; i--) {
        if (nums[i] < nums[i - 1] + nums[i - 2]) {
            result = nums[i] + nums[i - 1] + nums[i - 2];
            break;
        }
    }
    return result;
}

끝까지 조건을 만족하는 조합이 하나도 없으면 삼각형을 만들 수 없다는 뜻이므로 result는 초기값 0을 그대로 반환한다.

3

시간복잡도와 제출 결과

정렬 O(n log n)이 지배적이고, 이후 탐색은 최악의 경우에도 O(n)이라 전체 시간복잡도는 O(n log n)이다.

Takeaway

  • 삼각형 성립 조건은 가장 긴 변 하나만 기준으로 a + b > c만 확인하면 충분하다.
  • 둘레 최대화가 목표이므로 정렬 후 가장 큰 값들부터 검사하는 그리디가 성립한다.
  • 조건을 만족하지 않는 최댓값은 완전히 배제해도 안전하다 - 더 작은 값을 짝지어도 조건은 더 나빠질 뿐이다.
