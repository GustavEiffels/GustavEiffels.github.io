Array Partition

모각코 중 머리도 식힐 겸 풀어본 문제 회고

언어: Java 분류: 그리디 핵심 기법: 오름차순 정렬 후 짝 지어 최소값 합 최대화

leetcode.com/problems/array-partition

CH 1

풀이 회고

1

계기

모각코 하다가 집중이 안돼서 머리도 풀겸 풀어본 문제이다.

엄청 쉬운 문제라고 해서 봤는데, 항상 짝수인 배열이 주어지고 이를 크기가 2인 부분 집합으로 나누어,
이때 부분집합의 2수 중 작은 수를 모두 더했을 때 합이 최대가 되는 경우의 최대 값을 구하는 문제였다.

2

생각의 흐름

근데 생각해보면 부분집합의 합이 제일 크려면, 오름차순 정렬해서 순서대로 묶으면
자신과 가장 비슷한 수와 묶이기 때문에 추출되는 최소 값이 최대가 된다.

예시로 확인

예를 들어 1, 24, 2, 23, 4, 22 이렇게 묶이면 최소값의 합은 1 + 2 + 4 가 된다.

오름차순 정렬 후 1, 2, 4, 22, 23, 24 순서대로 묶으면 1 + 4 + 23 이 되어 더 큰 수를 얻을 수 있다.

핵심 아이디어 비슷한 크기끼리 짝을 지어야 짝에서 버려지는(작은) 값의 손해가 최소화된다. 정렬 후 인접한 두 값끼리 묶는 것이 최적이다.

그래서 이를 적용하려면 그냥 정렬하고 홀수번째 수만 더하면 된다고 생각하여 다음과 같이 풀었다.

3

최종 코드

ArrayPartition.java 
public int arrayPairSum(int[] nums) {
    Arrays.sort(nums);
    int result = 0;
    for(int i = 0; i<nums.length; i+=2){
        result += nums[i];
    }
    return result;
}

정렬 후 짝은 (nums[0], nums[1]), (nums[2], nums[3]), ... 형태로 자동 구성되고,
각 짝의 작은 값은 항상 짝수 인덱스(0, 2, 4...)에 위치하므로 그 값들만 더하면 답이 된다.

4

Takeaway

  • 짝의 최소값 합을 최대화하려면, 크기가 비슷한 수끼리 묶어야 손해가 최소화된다.
  • 오름차순 정렬 후 인접한 값끼리 짝을 지으면 그 조건이 자동으로 만족된다.
  • 정렬 후에는 짝수 인덱스(0, 2, 4...)에 있는 값들이 항상 각 짝의 최소값이다.
  • 구현: 정렬 -> 짝수 인덱스 값만 합산.
