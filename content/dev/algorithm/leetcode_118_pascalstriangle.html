Pascal's Triangle

결과를 손으로 나열해서 점화식을 찾아낸 뒤, 다시 한 줄짜리 배열로 압축해본 DP 풀이 과정

언어: Java 분류: 동적 계획법 (DP) 핵심 기법: row[i][j] = row[i-1][j-1] + row[i-1][j]

leetcode.com/problems/pascals-triangle

CH 1

풀이 회고

1

문제

dynamic-programming 태그 목록을 풀다가 만난 문제다.

numRows가 주어지면 파스칼의 삼각형을 그 줄 수만큼 만들어서
List<List<Integer>> 형태로 반환하면 된다.

2

첫 접근 - 답을 직접 나열해봄

바로 코드를 짜기보다, 먼저 손으로 결과를 적어보면서 규칙을 찾으려고 했다.

손으로 적어본 규칙 
1
1, 1
1, 1+1, 1            -> 1, 2, 1
1, 1+2, 2+1, 1       -> 1, 3, 3, 1
1, 1+3, 3+3, 3+1, 1  -> 1, 4, 6, 4, 1

적어보니 양 끝은 항상 1이고, 중간 값은 바로 이전 줄의 인접한 두 값을 더한 것이라는 게 보였다.

3

패턴 발견 - 점화식

정리하면 다음과 같은 점화식이다.

점화식 row[i][j] = row[i-1][j-1] + row[i-1][j] (단, j가 양 끝이면 항상 1)

즉 이전 줄(result.get(i-1))의 j-1번째와 j번째를 더하면 현재 줄의 j번째 값이 나온다.
그래서 이전 결과를 그대로 재사용하는 DP 방식으로 풀 수 있다고 판단했다.

4

기본 케이스 처리

public List<List<Integer>> generate(int numRows) {
    List<List<Integer>> result = new ArrayList<>();
    if (numRows == 1) {
        result.add(Arrays.asList(1));
        return result;
    }
    if (numRows == 2) {
        result.add(Arrays.asList(1));
        result.add(Arrays.asList(1, 1));
        return result;
    }

일반 케이스 - 점화식 적용

PascalsTriangle.java 
    result.add(Arrays.asList(1));
    result.add(Arrays.asList(1, 1));

    for (int i = 2; i < numRows; i++) {
        List<Integer> row = new ArrayList<>();
        row.add(1);
        for (int j = 1; j < i; j++) {
            row.add(result.get(i - 1).get(j - 1) + result.get(i - 1).get(j));
        }
        row.add(1);
        result.add(row);
    }
    return result;
}
numRows==1 / numRows==2 분기는 왜 있나 루프 진입 전에 0번, 1번 줄을 무조건 미리 넣어두기 때문에, numRows가 1이나 2일 때 더 채워지면 안 되는 줄까지 들어가는 걸 막기 위한 예외 처리다.

더 짧게 만들기

5

방법 - 배열 하나만 재사용 (in-place)

이전 줄을 별도로 저장하지 않고, row 하나를 계속 갈아 끼우면서
앞에 1을 끼워넣고 왼쪽에서 오른쪽으로 더해나가는 방식이다. 같은 점화식, 다른 구현이다.

PascalsTriangle.java 
public List<List<Integer>> generate(int numRows) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> row = new ArrayList<>();
    for (int i = 0; i < numRows; i++) {
        row.add(0, 1);
        for (int j = 1; j < row.size() - 1; j++) {
            row.set(j, row.get(j) + row.get(j + 1));
        }
        result.add(new ArrayList<>(row));
    }
    return result;
}

row.get(j+1)이 아직 갱신 전 값이라, 왼쪽부터 순서대로 덮어써도 안전하다.
result.get(i-1)처럼 이전 줄을 따로 참조할 필요가 없어진다.

O(n^2) In-place DP
6

Takeaway

  • 먼저 결과를 손으로 나열해서 규칙을 찾는 접근이 점화식 발견에 효과적이었다.
  • row[i][j] = row[i-1][j-1] + row[i-1][j], 양 끝은 항상 1.
  • 기본 풀이는 result 리스트 전체를 쌓아가며 이전 줄을 참조하는 방식이다.
  • 개선판은 row 하나만 재사용하는 in-place 갱신으로 코드를 줄였다.
