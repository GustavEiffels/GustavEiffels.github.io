Best Time to Buy and Sell Stock

매수/매도 시점을 따로 찾지 않고, 최솟값 하나만 들고 다니는 한 번의 순회로 푼 과정

언어: Java 분류: 동적 계획법 (DP) 핵심 기법: 최솟값 갱신 + 한 번의 순회

1

문제 개요

가격 배열이 주어지고, 한 번 사고 한 번 팔았을 때 낼 수 있는 최대 이익을 구하는 문제다.

2

접근 - 최솟값 하나만 들고 다니기

배열을 한 번 순회하면서 지금까지 본 가격 중 최솟값(minPrice)을 계속 갱신하고,
오늘 가격에서 그 최솟값을 뺀 값과 지금까지의 최댓값(result)을 비교했다.

매수 시점과 매도 시점을 따로 찾을 필요 없이, "지금까지 가장 쌌던 값" 하나만 유지하면
한 번의 루프로 끝나는 구조다.

3

최종 코드

BestTimeToBuyAndSellStock.java 
public int maxProfit(int[] prices) {
    int minPrice = prices[0];
    int result = 0;

    for (int i = 1; i < prices.length; i++) {
        minPrice = Math.min(minPrice, prices[i]);
        result = Math.max(result, prices[i] - minPrice);
    }
    return result;
}
O(n)
4

Takeaway

  • 매수/매도 시점을 각각 찾을 필요 없이, 지금까지의 최솟값 하나만 유지하면 된다.
  • 한 번의 순회(O(n))로 충분하고, 별도의 DP 배열이 필요 없는 형태다.
