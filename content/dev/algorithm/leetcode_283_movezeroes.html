Move Zeroes

Queue 기반 풀이를 먼저 통과시킨 뒤, in-place 조건을 만족시키기 위해 투 포인터로 개선한 회고

언어: Java 분류: Array / Two Pointer 핵심 기법: 느린 포인터로 non-zero 삽입 위치를 추적하며 in-place swap

leetcode.com/problems/move-zeroes

1

문제와 손으로 먼저 정리한 접근

정수 배열 nums가 주어졌을 때, 0이 아닌 값들의 상대 순서는 유지한 채 모든 0을 배열 뒤쪽으로 옮기는 문제다. 배열을 직접 수정(in-place)해야 하며 반환값은 없다.
예시: [0, 1, 0, 3, 12] → [1, 3, 12, 0, 0]

코드를 바로 짜기 전에 노트에 흐름을 먼저 적었다. 배열을 한 번 순회하면서 값이 0인 위치를 확인하고, 원본과 같은 크기가 되도록 0이 아닌 값들을 먼저 큐에 담은 뒤 모자란 만큼 0을 뒤에 채워 넣는다. 그 다음 큐에서 순서대로 꺼내 배열에 다시 덮어쓴다.

핵심 아이디어 0이 아닌 값만 먼저 큐에 쌓고, 부족한 자리를 0으로 채운 뒤 통째로 되돌려 쓰면 순서를 유지하면서 0을 뒤로 보낼 수 있다.
2

1차 풀이 — Queue 기반

MoveZeroes.java (Queue) 
public void moveZeroes(int[] nums) {
    Queue<Integer> queue = new LinkedList<>();
    for (int num : nums) {
        if (num != 0) {
            queue.offer(num);
        }
    }
    while (nums.length != queue.size()) {
        queue.offer(0);
    }
    for (int i = 0; i < nums.length; i++) {
        nums[i] = queue.poll();
    }
}

0이 아닌 값을 큐에 순서대로 적재하고, 큐 크기가 배열 길이와 같아질 때까지 0으로 채운 뒤, 큐에서 순서대로 꺼내 배열에 되돌려 쓴다. 노트에 적은 계획을 그대로 옮긴 구현이다.

2차 풀이 — Two Pointer (in-place)

LeetCode 283은 원 문제에 in-place, O(1) 추가 공간이라는 follow-up 조건이 붙어 있다. 큐 없이 배열 안에서만 값을 옮기려면 두 개의 포인터가 필요하다. insertPos는 "다음 non-zero 값이 놓여야 할 위치"를 가리키는 느린 포인터이고, i는 배열 전체를 훑는 빠른 포인터다. nums[i]가 0이 아니면 insertPos 위치와 swap하고 한 칸 전진시킨다.

MoveZeroes.java (Two Pointer) 
public void moveZeroesTwoPointer(int[] nums) {
    int insertPos = 0; // 다음 non-zero가 들어갈 위치
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] != 0) {
            int temp = nums[insertPos];
            nums[insertPos] = nums[i];
            nums[i] = temp;
            insertPos++;
        }
    }
}

Takeaway

  • 0이 아닌 값을 앞으로 모으고 나머지를 0으로 채운다는 아이디어는 큐로도, in-place swap으로도 구현 가능하다.
  • Queue(LinkedList) 방식은 정답이지만 오토박싱·노드 할당·O(n) 추가 공간 때문에 런타임/메모리 모두 하위권이었다.
  • 투 포인터(insertPos + i)는 배열 안에서만 swap하므로 O(1) 추가 공간, 즉 in-place follow-up 조건을 만족한다.
